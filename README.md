# 海老名市議会 一般質問生成ツール

## このツールでできること

このツールは、**市議会の一般質問を自動で作ってくれるソフト**です。

具体的には、以下のことを自動で行います：

1. **海老名市の行政情報を自動収集** — 市の公式サイトから新着情報、予算、施政方針などを取ってきます
2. **国や県の情報も自動収集** — 総務省・こども家庭庁・デジタル庁・神奈川県などから、法令改正・補助金・交付金の最新情報を取ってきます
3. **市議会の過去の議事録も収集** — 過去の質問と重複しないよう、会議録データも取得します
4. **過去3年間のデータを蓄積** — 収集した情報を3年間保管し、新着情報との重複を自動削除しながら蓄積します
5. **ヒアリング項目を自動生成** — 一般質問の擦り合わせ期間に行政側へ確認すべき事項を自動で作成します
6. **ヒアリング回答を踏まえて質問を生成** — 行政側の回答を入力すると、それを踏まえたより精度の高い質問案を作成します
7. **カテゴリを選んで質問を生成** — 「子育て・教育」「防災・安全」など8つの分野から選べます
8. **行政の想定答弁も自動生成** — 各質問に対して、市長や部長がどう答えそうかの予測も付きます
9. **再質問案も自動生成** — 想定答弁の弱い部分を突く再質問案も作ります

---

## ワークフロー（全体の流れ）

このツールは、以下の4ステップで使います：

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  Step 1: collect（情報収集）                                  │
│    行政情報を収集し、マスターストアに蓄積（3年間保持）           │
│                     ↓                                        │
│  Step 2: hearing（ヒアリング項目生成）                         │
│    蓄積データからヒアリング項目を自動生成                       │
│                     ↓                                        │
│  Step 3: 行政側へヒアリング実施（手動）                        │
│    生成されたヒアリングシートを元に担当部署へ確認               │
│    回答テンプレート(JSON)に回答を入力                          │
│                     ↓                                        │
│  Step 4: refine（一般質問生成）                               │
│    ヒアリング回答を踏まえた詳細な一般質問を生成                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

> **従来通りの使い方もできます：** ヒアリングを省略して、`collect` → `generate` で直接質問を生成することも可能です。

## どこから情報を集めてくるの？

このツールは、以下のサイトから自動で情報を集めます。

### 海老名市（市の情報）

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 市の最新ニュース | 海老名市公式サイト 新着更新情報 |
| 予算・お金の情報 | 財政情報・予算状況のページ |
| 市長の方針 | 市長施政方針のページ |
| まちの計画 | 総合計画・政策のページ |
| 議会の情報 | 議会事務局のページ |

### 国の情報（法令・補助金・交付金）

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 地方行政に関する国の動き | 総務省の報道資料 |
| 地方向けのお金の制度 | 総務省の地方財政制度ページ |
| 子育てに関する国の施策 | こども家庭庁の報道発表 |
| デジタル化に関する国の施策 | デジタル庁の新着情報 |
| 地方を元気にする補助金 | 内閣府の地方創生ページ |

### 神奈川県の情報

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 県のニュース | 神奈川県の記者発表資料 |
| 県の補助金・助成金 | 神奈川県の補助金情報ページ |
| 市町村向けの連絡事項 | 神奈川県の市町村向け情報ページ |

### 議会の過去の記録

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 過去の質問と答弁の記録 | 海老名市議会の会議録・議事録 |
| 定例会・臨時会の記録 | 海老名市議会の定例会ページ |

## データ蓄積の仕組み（3年間保持）

このツールは、収集した情報を **3年間蓄積** します。

```
┌─────────────────────────────────────────────────┐
│           マスターストア (master_articles.json)     │
│                                                   │
│  ┌─ 2024年の収集データ ──────────────────────┐    │
│  │  海老名市ニュース (50件), 国の施策 (30件)...│    │
│  └──────────────────────────────────────────┘    │
│  ┌─ 2025年の収集データ ──────────────────────┐    │
│  │  海老名市ニュース (48件), 国の施策 (35件)...│    │
│  └──────────────────────────────────────────┘    │
│  ┌─ 2026年の収集データ（最新） ─────────────┐    │
│  │  海老名市ニュース (52件), 国の施策 (28件)...│    │
│  └──────────────────────────────────────────┘    │
│                                                   │
│  ・新着情報との重複は URL で自動判定・削除         │
│  ・3年を超えた古い記事は自動的に削除               │
│  ・collect を実行するたびに蓄積が増えていく        │
└─────────────────────────────────────────────────┘
```

- **保存場所：** `data/master_articles.json`
- **重複削除：** 同じURLの記事は2回保存されません
- **自動削除：** 収集日から3年を超えた記事は自動的に削除されます
- **従来互換：** 各回の収集スナップショット（`data/articles_*.json`）も引き続き保存されます

### Step 1：Node.js をインストールする

このツールは「**Node.js**」というソフトウェアの上で動きます。
Node.js は無料で使える、世界中で広く使われているプログラム実行環境です。

#### Windows の場合

1. ブラウザで https://nodejs.org/ にアクセスします
2. **「LTS」**（推奨版）と書かれた緑色のボタンをクリックしてダウンロード
3. ダウンロードしたファイル（`node-vXX.X.X-x64.msi`）をダブルクリック
4. インストーラーの指示に従って「Next」を押していけばOKです（すべてデフォルト設定で問題ありません）
5. 最後に「Finish」を押して完了

#### Mac の場合

1. ブラウザで https://nodejs.org/ にアクセスします
2. **「LTS」**（推奨版）と書かれた緑色のボタンをクリックしてダウンロード
3. ダウンロードしたファイル（`node-vXX.X.X.pkg`）をダブルクリック
4. インストーラーの指示に従って進めてください

#### インストールできたか確認する

インストール後、**ターミナル**（コマンドを入力する黒い画面）を開きます。

**ターミナルの開き方：**
- **Windows**: キーボードの `Windows キー` を押して、「**PowerShell**」と入力して表示されたアプリをクリック
- **Mac**: 「アプリケーション」→「ユーティリティ」→「**ターミナル**」をダブルクリック

ターミナルが開いたら、以下を入力して `Enter` キーを押してください：

```bash
node --version
```

`v22.x.x` のようにバージョン番号が表示されれば成功です。
（数字はインストール時期によって異なります）

このツールは複数のライブラリ（他の人が作った便利なプログラム部品）を使って動いています。
`npm install` コマンドで、それらを一括ダウンロードします。


もし「見つかりません」「No such file」と出た場合は、正しいフォルダに移動できていません。
以下のように `cd` コマンドでフォルダを移動してください：

```bash
# Git clone した場合
cd politics-infomation-collect

# ZIPダウンロードした場合（Windows 例）
cd C:\Users\あなたのユーザー名\Downloads\politics-infomation-collect-main

# ZIPダウンロードした場合（Mac 例）
cd ~/Downloads/politics-infomation-collect-main
```

#### 3-2. npm install を実行する

ターミナルで以下を入力して Enter を押します：

```bash
npm install
```

#### 3-3. 実行中の画面について

実行すると、以下のようにたくさんの文字が流れます（30秒〜1分ほどかかることがあります）：

```
npm warn deprecated ...
added 150 packages, and audited 151 packages in 30s
```

**気にしなくてよい表示：**
- `npm warn deprecated ...` → 古いライブラリの警告です。動作に影響ありません
- `npm warn ...` → 警告全般。`warn` は問題ではありません

**成功の目印：** 最後の行に以下のような表示が出ていれば成功です：

```
added XX packages, and audited XX packages in XXs
```

（`XX` の部分は数字が入ります）

#### 3-4. エラーが出た場合

| エラー内容 | 原因と対処法 |
|-----------|-------------|
| `npm: command not found` | Node.js が正しくインストールされていません。Step 1 に戻ってください |
| `EACCES: permission denied` | Mac/Linuxで権限エラーが出た場合、コマンドの先頭に `sudo` を付けて再実行してください：`sudo npm install` |
| `ENOTFOUND` / `network error` | インターネットに接続されていません。Wi-Fi や LAN の接続を確認してください |
| `npm ERR! code ERESOLVE` | `npm install --legacy-peer-deps` と入力して再実行してみてください |

すべてうまくいくと、フォルダ内に `node_modules` というフォルダが新しく作成されます。
これが依存パッケージの実体です（中身を触る必要はありません）。

### Step 4：Anthropic API キーを取得する

質問の自動生成には **Anthropic**（AI「Claude」の開発元）の API キーが必要です。
API キーとは「このソフトからClaude を使っていいですよ」という許可証のようなものです。

1. ブラウザで https://console.anthropic.com/ にアクセス
2. アカウントがなければ **「Sign up」** をクリックして新規登録します（メールアドレスが必要）
3. ログインしたら、左側メニューの **「API Keys」** をクリック
4. **「Create Key」** ボタンをクリック
5. 名前を入力します（例：`ebina-council`）。名前は何でもOKです
6. 表示されたキー（`sk-ant-...` で始まる長い文字列）を**コピーして安全な場所に保存**してください

**重要：このキーは一度しか表示されません！** 必ずメモ帳などにコピーしてください。
もし忘れた場合は、古いキーを削除して新しいキーを作り直せばOKです。

> **料金について：** API の利用には料金がかかります（1回の質問生成で数十円程度）。
> 初回登録時に無料クレジットが付与される場合があります。

### Step 5：API キーを安全に設定する

Step 4 で取得した API キーを、このツールに教える作業です。

> **注意：** API キーはパスワードと同じです。`.env` ファイルに書くと誤って GitHub にアップロードしてしまう危険があるため、**環境変数として設定する方法を推奨**します。

#### 方法A：環境変数で設定する（推奨）

環境変数はターミナルの設定ファイルに書くため、リポジトリの外に置かれ、誤ってGitHubに公開される心配がありません。

**Windows（PowerShell）の場合：**

1. PowerShell で以下を実行します：
   ```powershell
   [System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-ここに実際のキーを貼り付け", "User")
   ```
2. PowerShell を一度閉じて開き直します
3. 設定できたか確認：
   ```powershell
   echo $env:ANTHROPIC_API_KEY
   ```
   キーが表示されればOKです。

**Mac / Linux の場合：**

1. ターミナルで以下を実行します（`sk-ant-...` の部分を実際のキーに置き換え）：
   ```bash
   echo 'export ANTHROPIC_API_KEY="sk-ant-ここに実際のキーを貼り付け"' >> ~/.bashrc
   ```
   > zsh を使っている場合は `~/.bashrc` を `~/.zshrc` に変えてください。
   > どちらかわからない場合は `echo $SHELL` で確認できます。
2. 設定を反映します：
   ```bash
   source ~/.bashrc
   ```
3. 設定できたか確認：
   ```bash
   echo $ANTHROPIC_API_KEY
   ```
   キーが表示されればOKです。

#### 方法B：.env ファイルで設定する（非推奨）

> この方法は手軽ですが、`.env` ファイルを誤ってGitHubにアップロードするリスクがあります。
> 方法Aの環境変数設定を推奨します。

**Windows（PowerShell）の場合：**
```powershell
copy .env.example .env
notepad .env
```

**Mac / Linux の場合：**
```bash
cp .env.example .env
open -e .env    # Mac の場合
nano .env       # Linux の場合
```

開いたファイルの `ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxx` の部分を実際のキーに書き換えて保存します。

### Step 7：実行する

いよいよ実行です。推奨ワークフローに沿って説明します。

#### 使い方 (A)：推奨ワークフロー（ヒアリング→質問生成）

##### Step 7-1：情報を収集する

```bash
npm run collect
```

海老名市・国の省庁・神奈川県・市議会のウェブサイトにアクセスして、最新の行政情報を自動で集めます。
集めた情報は **マスターストアに蓄積** されます（3年間保持、重複は自動削除）。

```
=== 行政情報収集 ===

[モード] 全ソース収集（海老名市 + 国 + 県 + 議事録）

[収集中] 新着更新情報: https://www.city.ebina.kanagawa.jp/newslist.html
  -> 8 件の情報を取得
...

--- マスターストア ---
  新規追加: 35 件
  期限切れ削除: 0 件
  合計蓄積: 142 件
```

> **海老名市の情報だけ集めたい場合：**
> ```bash
> node dist/index.js collect --local-only
> ```

##### Step 7-2：ヒアリング項目を生成する

```bash
node dist/index.js hearing
```

蓄積データを分析し、行政の各担当部署へ確認すべきヒアリング項目を自動生成します。

**出力されるファイル：**
- `output/ヒアリング項目_*.md` — 印刷してヒアリング時に使えるシート
- `data/hearing_responses_*.json` — 回答入力用テンプレート

```
=== ヒアリング項目生成 ===

1. 令和7年度の子育て支援施策の方向性について
   担当部署: 子育て支援課
   - 来年度の待機児童対策として新たに計画している施策はありますか？
   - 国の新規補助金について、市として申請の予定はありますか？

2. デジタル化推進に伴う市民サービスの向上について
   担当部署: 情報システム課
   - マイナンバーカードを活用した新サービスの計画はありますか？
...

--- 次のステップ ---
1. ヒアリングシートを参考に行政側へヒアリングを実施
2. 回答テンプレートの "answer" 欄に回答を入力
3. 「refine」コマンドで一般質問を生成
```

##### Step 7-3：ヒアリング回答を入力する

`data/hearing_responses_*.json` ファイルをテキストエディタで開き、各質問の `"answer"` 欄に行政側の回答を入力します。

```json
{
  "responses": [
    {
      "topic": "令和7年度の子育て支援施策の方向性について",
      "answers": [
        {
          "question": "来年度の待機児童対策として新たに計画している施策はありますか？",
          "answer": "ここに回答を入力 → 例：来年度は小規模保育施設を2箇所新設予定です"

        {

        }

    }
  ]
}
```

##### Step 7-4：ヒアリング回答を踏まえて一般質問を生成する

```bash
node dist/index.js refine
```

ヒアリングで得た情報と蓄積データを組み合わせて、より踏み込んだ一般質問を生成します。

```
=== ヒアリング回答に基づく一般質問生成 ===

対象記事数: 142 件
ヒアリング回答: 12/15 問回答済み

質問生成完了: 4 項目
Markdown: output/一般質問_2026-02-16_10-00-00.md
```

#### 使い方 (B)：ヒアリングなしで直接質問を生成する（従来の使い方）

```bash
# 情報収集から質問生成まで一括実行
node dist/index.js run

# カテゴリを指定して実行
node dist/index.js run --category "子育て・教育"

# 全カテゴリで生成（メニューを表示しない）
node dist/index.js run --all
```

#### 使い方 (C)：毎朝自動で実行する

```bash
npm run schedule
```

パソコンをつけたままにしておくと、**2週間に1度（朝8時）**に自動で情報収集と質問生成を行います。
止めたいときは `Ctrl + C`（キーボードの Ctrl キーを押しながら C キーを押す）で停止できます。

### トラブルシューティング（うまくいかない時）

| こんな症状が出たら | こうしてください |
|------------------|---------------|
| `node: command not found` と表示される | Node.js がインストールされていません。Step 1 をやり直してください |
| `npm install` でエラーが出る | インターネット接続を確認してください |
| `ANTHROPIC_API_KEY が設定されていません` と表示される | Step 5 で環境変数の設定が正しくできていません。`echo $ANTHROPIC_API_KEY`（Mac/Linux）または `echo $env:ANTHROPIC_API_KEY`（Windows PowerShell）で設定を確認してください |
| `エラー:` が出て収集先のサイトが読めない | そのサイトがメンテナンス中かもしれません。他のサイトの収集は続行されるので問題ありません |
| 収集記事が 0 件 | インターネット接続を確認してください。時間をおいて再実行してみてください |
| 質問生成で `401` エラーが出る | API キーが間違っています。環境変数の設定を確認してください |
| 質問生成で `429` エラーが出る | API の利用上限に達しました。Anthropic のアカウントにクレジットがあるか確認してください |
| 質問が生成されるまで時間がかかる | AI が考えている最中です。通常1〜2分かかります。そのまま待ってください |
| `ヒアリング回答がすべて空です` と表示される | 回答テンプレートの `"answer"` 欄に回答を入力してから `refine` を実行してください |

## 環境変数（設定の変更）

以下の設定は環境変数で変更できます。通常は `ANTHROPIC_API_KEY` だけ設定すれば動きます。

| 設定名 | 必須？ | 初期値 | 説明 |
|--------|-------|--------|------|
| `ANTHROPIC_API_KEY` | **必須** | - | Anthropic の API キー（`sk-ant-...`で始まる文字列） |
| `OUTPUT_DIR` | 任意 | `./output` | 質問案ファイルの出力先フォルダ |
| `DATA_DIR` | 任意 | `./data` | 収集データの保存先フォルダ |
| `CRON_SCHEDULE` | 任意 | `0 8 */14 * *` | 自動実行の間隔（デフォルト：2週間に1度 朝8時） |
| `MAX_ARTICLES` | 任意 | `200` | 1回の収集で取得する記事の最大数 |

> `.env` ファイルでもこれらの設定を上書きできます（`ANTHROPIC_API_KEY` を除く）。
> API キーは環境変数での設定を推奨します（Step 5 参照）。
