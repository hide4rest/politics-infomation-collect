# 海老名市議会 一般質問生成ツール

神奈川県海老名市の公式サイトから行政情報を自動収集し、市議会定例会での一般質問の項目と詳細な質問内容を生成するCLIアプリケーションです。

## 機能

- **行政情報の自動収集**: 海老名市公式サイトから新着情報、財政情報、施政方針、市議会情報等をスクレイピング
- **一般質問の自動生成**: Claude APIを活用し、収集情報に基づいた具体的な一般質問を生成
- **定期実行**: cronスケジュールによる自動収集・生成
- **Markdown出力**: 議会質問として使いやすいMarkdown形式で出力

## 収集対象

| カテゴリ | 収集元 |
|---------|-------|
| 新着情報 | 海老名市公式サイト 新着更新情報 |
| 財政・予算 | 財政情報・予算状況ページ |
| 施政方針 | 市長施政方針ページ |
| 計画・政策 | 総合計画・政策ページ |
| 市議会 | 議会事務局ページ |

## 初心者向け セットアップガイド（ゼロからの手順）

パソコンにこのツールをインストールして動かすまでの手順を、ゼロから説明します。

### 前提：必要なもの

| 必要なもの | 説明 |
|-----------|------|
| パソコン | Windows / Mac / Linux いずれでもOK |
| インターネット接続 | ソフトのダウンロードとWebサイトの収集に必要 |
| Anthropic APIキー | 質問の自動生成に必要（後述） |

---

### Step 1：Node.js をインストールする

このツールは「Node.js」というソフトウェアの上で動きます。まず Node.js をインストールしてください。

#### Windows の場合

1. ブラウザで https://nodejs.org/ にアクセスします
2. **「LTS」**（推奨版）と書かれた緑色のボタンをクリックしてダウンロード
3. ダウンロードしたファイル（`node-vXX.X.X-x64.msi`）をダブルクリック
4. インストーラーの指示に従って「Next」を押していけばOKです（すべてデフォルト設定で問題ありません）

#### Mac の場合

1. ブラウザで https://nodejs.org/ にアクセスします
2. **「LTS」**（推奨版）と書かれた緑色のボタンをクリックしてダウンロード
3. ダウンロードしたファイル（`node-vXX.X.X.pkg`）をダブルクリック
4. インストーラーの指示に従って進めてください

#### インストール確認

インストール後、**ターミナル**（コマンドを入力する画面）を開きます。

- **Windows**: スタートメニューで「PowerShell」と検索して開く
- **Mac**: 「アプリケーション」→「ユーティリティ」→「ターミナル」を開く

開いたら以下を入力して Enter キーを押してください：

```bash
node --version
```

`v22.x.x` のようにバージョンが表示されれば成功です。

---

### Step 2：このツールのソースコードをダウンロードする

#### 方法A：Git を使う場合（Gitが入っている方）

ターミナルで以下を入力します：

```bash
git clone https://github.com/hide4rest/politics-infomation-collect.git
cd politics-infomation-collect
```

#### 方法B：ZIPでダウンロードする場合（Gitがわからない方）

1. ブラウザでこのリポジトリのページを開きます
2. 緑色の **「Code」** ボタンをクリック
3. **「Download ZIP」** をクリック
4. ダウンロードしたZIPファイルを展開（右クリック→「すべて展開」）
5. ターミナルで展開したフォルダに移動します：

```bash
# Windows の場合（例）
cd C:\Users\あなたのユーザー名\Downloads\politics-infomation-collect-main

# Mac の場合（例）
cd ~/Downloads/politics-infomation-collect-main
```

---

### Step 3：依存パッケージをインストールする

ターミナルで以下を入力して Enter を押します：

```bash
npm install
```

たくさんの文字が流れますが、最後に `added XX packages` と表示されれば成功です。

---

### Step 4：Anthropic APIキーを取得する

質問の自動生成には Anthropic（Claude の開発元）の APIキーが必要です。

1. ブラウザで https://console.anthropic.com/ にアクセス
2. アカウントがなければ **「Sign up」** で新規登録します（メールアドレスが必要）
3. ログイン後、左側メニューの **「API Keys」** をクリック
4. **「Create Key」** ボタンをクリック
5. 名前を入力（例：`ebina-council`）して作成
6. 表示されたキー（`sk-ant-...` で始まる文字列）を**コピーして安全な場所に保存**してください
   - **注意：このキーは一度しか表示されません！**

> APIの利用には料金がかかります（1回の質問生成で数十円程度）。
> 初回登録時に無料クレジットが付与される場合があります。

---

### Step 5：環境変数を設定する

#### Windows（PowerShell）の場合

```powershell
copy .env.example .env
notepad .env
```

#### Mac / Linux の場合

```bash
cp .env.example .env
open .env    # Mac の場合
# または
nano .env    # ターミナル内で編集する場合
```

開いたファイルの中の以下の行を編集します：

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxx
```

`sk-ant-xxxxxxxxxxxxxxxxx` の部分を、Step 4 で取得した実際のAPIキーに書き換えて保存してください。

---

### Step 6：ビルドする

ターミナルで以下を入力します：

```bash
npm run build
```

何もエラーが出なければ成功です。

---

### Step 7：実行する

以下のいずれかのコマンドで実行できます。

#### 行政情報の収集だけ行う（APIキー不要）

```bash
npm run collect
```

海老名市公式サイトから最新の行政情報を収集し、`data/` フォルダに保存します。

#### 収集 → 質問生成 を一括で行う（APIキー必要）

```bash
node dist/index.js run
```

情報収集から質問生成まで自動で行い、`output/` フォルダに質問案を出力します。

#### 毎朝自動で実行する

```bash
npm run schedule
```

パソコンを起動したままにしておくと、毎朝8時に自動で収集と質問生成を行います。
`Ctrl + C` で停止できます。

---

### 結果の確認方法

実行後、`output/` フォルダの中にファイルが生成されます：

- **`一般質問_2026-02-15_08-00-00.md`** — 質問案（テキストエディタやWordで開けます）
- **`questions_2026-02-15_08-00-00.json`** — 質問データ（プログラム用）

`.md` ファイルをダブルクリックするか、メモ帳やWordで開いてください。

---

### トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| `node: command not found` | Node.js が正しくインストールされていません。Step 1 をやり直してください |
| `npm install` でエラーが出る | インターネット接続を確認してください |
| `ANTHROPIC_API_KEY が設定されていません` | `.env` ファイルが正しく作成・編集されているか確認してください |
| 収集記事が0件 | 海老名市公式サイトがメンテナンス中の可能性があります。時間をおいて再実行してください |
| 質問生成でエラーが出る | APIキーが正しいか、Anthropicアカウントにクレジットがあるか確認してください |

## 出力例

`output/` ディレクトリに以下のファイルが生成されます：

- `一般質問_YYYY-MM-DD_HH-MM-SS.md` — Markdown形式の質問案
- `questions_YYYY-MM-DD_HH-MM-SS.json` — JSON形式の質問データ

### 出力サンプル（Markdown）

```markdown
# 海老名市議会 一般質問（案）

## 1. 令和7年度予算における子育て支援施策について

### 背景・根拠
海老名市の令和7年度一般会計予算において...

### 質問項目

#### （1）保育施設の整備計画について

**質問内容：**
> 令和7年度予算における保育施設整備費の具体的な配分と、
> 待機児童解消に向けた目標数値をお聞かせください。
```

## 環境変数

| 変数名 | 必須 | デフォルト | 説明 |
|--------|------|-----------|------|
| `ANTHROPIC_API_KEY` | ○ | - | Anthropic APIキー |
| `OUTPUT_DIR` | - | `./output` | 出力ディレクトリ |
| `DATA_DIR` | - | `./data` | データ保存ディレクトリ |
| `CRON_SCHEDULE` | - | `0 8 * * *` | 定期実行スケジュール |
| `MAX_ARTICLES` | - | `50` | 最大収集記事数 |
