# 海老名市議会 一般質問生成ツール

## このツールでできること

このツールは、**市議会の一般質問を自動で作ってくれるソフト**です。

具体的には、以下のことを自動で行います：

1. **海老名市の行政情報を自動収集** — 市の公式サイトから新着情報、予算、施政方針などを取ってきます
2. **国や県の情報も自動収集** — 総務省・こども家庭庁・デジタル庁・神奈川県などから、法令改正・補助金・交付金の最新情報を取ってきます
3. **市議会の過去の議事録も収集** — 過去の質問と重複しないよう、会議録データも取得します
4. **カテゴリを選んで質問を生成** — 「子育て・教育」「防災・安全」など8つの分野から選べます
5. **行政の想定答弁も自動生成** — 各質問に対して、市長や部長がどう答えそうかの予測も付きます
6. **再質問案も自動生成** — 想定答弁の弱い部分を突く再質問案も作ります

## どこから情報を集めてくるの？

このツールは、以下のサイトから自動で情報を集めます。

### 海老名市（市の情報）

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 市の最新ニュース | 海老名市公式サイト 新着更新情報 |
| 予算・お金の情報 | 財政情報・予算状況のページ |
| 市長の方針 | 市長施政方針のページ |
| まちの計画 | 総合計画・政策のページ |
| 議会の情報 | 議会事務局のページ |

### 国の情報（法令・補助金・交付金）

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 地方行政に関する国の動き | 総務省の報道資料 |
| 地方向けのお金の制度 | 総務省の地方財政制度ページ |
| 子育てに関する国の施策 | こども家庭庁の報道発表 |
| デジタル化に関する国の施策 | デジタル庁の新着情報 |
| 地方を元気にする補助金 | 内閣府の地方創生ページ |

### 神奈川県の情報

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 県のニュース | 神奈川県の記者発表資料 |
| 県の補助金・助成金 | 神奈川県の補助金情報ページ |
| 市町村向けの連絡事項 | 神奈川県の市町村向け情報ページ |

### 議会の過去の記録

| 何の情報？ | どこから集める？ |
|-----------|---------------|
| 過去の質問と答弁の記録 | 海老名市議会の会議録・議事録 |
| 定例会・臨時会の記録 | 海老名市議会の定例会ページ |

### Step 1：Node.js をインストールする

このツールは「**Node.js**」というソフトウェアの上で動きます。
Node.js は無料で使える、世界中で広く使われているプログラム実行環境です。

#### Windows の場合

1. ブラウザで https://nodejs.org/ にアクセスします
2. **「LTS」**（推奨版）と書かれた緑色のボタンをクリックしてダウンロード
3. ダウンロードしたファイル（`node-vXX.X.X-x64.msi`）をダブルクリック
4. インストーラーの指示に従って「Next」を押していけばOKです（すべてデフォルト設定で問題ありません）
5. 最後に「Finish」を押して完了

#### Mac の場合

1. ブラウザで https://nodejs.org/ にアクセスします
2. **「LTS」**（推奨版）と書かれた緑色のボタンをクリックしてダウンロード
3. ダウンロードしたファイル（`node-vXX.X.X.pkg`）をダブルクリック
4. インストーラーの指示に従って進めてください

#### インストールできたか確認する

インストール後、**ターミナル**（コマンドを入力する黒い画面）を開きます。

**ターミナルの開き方：**
- **Windows**: キーボードの `Windows キー` を押して、「**PowerShell**」と入力して表示されたアプリをクリック
- **Mac**: 「アプリケーション」→「ユーティリティ」→「**ターミナル**」をダブルクリック

ターミナルが開いたら、以下を入力して `Enter` キーを押してください：

```bash
node --version
```

`v22.x.x` のようにバージョン番号が表示されれば成功です。
（数字はインストール時期によって異なります）

### Step 3：依存パッケージをインストールする

このツールは複数のライブラリ（他の人が作った便利なプログラム部品）を使って動いています。
`npm install` コマンドで、それらを一括ダウンロードします。

#### 3-1. ターミナルがツールのフォルダにいることを確認する

まず、ターミナルが正しいフォルダ（Step 2 でダウンロードしたフォルダ）にいることを確認します。
以下を入力して Enter を押してください：

**Windows（PowerShell）の場合：**
```powershell
dir package.json
```

**Mac / Linux の場合：**
```bash
ls package.json
```

`package.json` というファイルが表示されればOKです。
もし「見つかりません」「No such file」と出た場合は、正しいフォルダに移動できていません。
以下のように `cd` コマンドでフォルダを移動してください：

```bash
# Git clone した場合
cd politics-infomation-collect

# ZIPダウンロードした場合（Windows 例）
cd C:\Users\あなたのユーザー名\Downloads\politics-infomation-collect-main

# ZIPダウンロードした場合（Mac 例）
cd ~/Downloads/politics-infomation-collect-main
```

#### 3-2. npm install を実行する

ターミナルで以下を入力して Enter を押します：

```bash
npm install
```

#### 3-3. 実行中の画面について

実行すると、以下のようにたくさんの文字が流れます（30秒〜1分ほどかかることがあります）：

```
npm warn deprecated ...
added 150 packages, and audited 151 packages in 30s
```

**気にしなくてよい表示：**
- `npm warn deprecated ...` → 古いライブラリの警告です。動作に影響ありません
- `npm warn ...` → 警告全般。`warn` は問題ではありません

**成功の目印：** 最後の行に以下のような表示が出ていれば成功です：

```
added XX packages, and audited XX packages in XXs
```

（`XX` の部分は数字が入ります）

#### 3-4. エラーが出た場合

| エラー内容 | 原因と対処法 |
|-----------|-------------|
| `npm: command not found` | Node.js が正しくインストールされていません。Step 1 に戻ってください |
| `EACCES: permission denied` | Mac/Linuxで権限エラーが出た場合、コマンドの先頭に `sudo` を付けて再実行してください：`sudo npm install` |
| `ENOTFOUND` / `network error` | インターネットに接続されていません。Wi-Fi や LAN の接続を確認してください |
| `npm ERR! code ERESOLVE` | `npm install --legacy-peer-deps` と入力して再実行してみてください |

すべてうまくいくと、フォルダ内に `node_modules` というフォルダが新しく作成されます。
これが依存パッケージの実体です（中身を触る必要はありません）。

### Step 4：Anthropic API キーを取得する

質問の自動生成には **Anthropic**（AI「Claude」の開発元）の API キーが必要です。
API キーとは「このソフトからClaude を使っていいですよ」という許可証のようなものです。

1. ブラウザで https://console.anthropic.com/ にアクセス
2. アカウントがなければ **「Sign up」** をクリックして新規登録します（メールアドレスが必要）
3. ログインしたら、左側メニューの **「API Keys」** をクリック
4. **「Create Key」** ボタンをクリック
5. 名前を入力します（例：`ebina-council`）。名前は何でもOKです
6. 表示されたキー（`sk-ant-...` で始まる長い文字列）を**コピーして安全な場所に保存**してください

**重要：このキーは一度しか表示されません！** 必ずメモ帳などにコピーしてください。
もし忘れた場合は、古いキーを削除して新しいキーを作り直せばOKです。

> **料金について：** API の利用には料金がかかります（1回の質問生成で数十円程度）。
> 初回登録時に無料クレジットが付与される場合があります。

### Step 5：環境変数を設定する（API キーをツールに教える）

Step 4 で取得した API キーを、このツールに教える作業です。

#### 5-1. 設定ファイルを作る

**Windows（PowerShell）の場合：**
```powershell
copy .env.example .env
```

**Mac / Linux の場合：**
```bash
cp .env.example .env
```

#### 5-2. 設定ファイルを開いて編集する

**Windows の場合：**
```powershell
notepad .env
```

**Mac の場合：**
```bash
open -e .env
```

#### 5-3. API キーを書き込む

開いたファイルの中に以下のような行があります：

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxx
```

`sk-ant-xxxxxxxxxxxxxxxxx` の部分を、**Step 4 でコピーした実際の API キー** に書き換えてください。

書き換え例：
```
ANTHROPIC_API_KEY=sk-ant-api03-abcdef123456789...
```

書き換えたら、ファイルを**保存して閉じて**ください。

### Step 7：実行する

いよいよ実行です。目的に応じて、以下の3つの使い方があります。

#### 使い方 (A)：まずは情報収集だけ試す（API キー不要）

```bash
npm run collect
```

**これは何をするの？**
海老名市・国の省庁・神奈川県・市議会のウェブサイトにアクセスして、最新の行政情報を自動で集めてきます。
集めた情報は `data/` フォルダに保存されます。

**実行すると、こんな画面が出ます：**
```
=== 行政情報収集 ===

[モード] 全ソース収集（海老名市 + 国 + 県 + 議事録）

[収集中] 新着更新情報: https://www.city.ebina.kanagawa.jp/newslist.html
  -> 8 件の情報を取得
[収集中] 総務省 報道資料（地方行財政）: https://www.soumu.go.jp/...
  -> 5 件の情報を取得
...

--- カテゴリ別集計 ---
  新着情報: 8 件
  国の法令・制度: 12 件
  補助金・交付金: 6 件
  県の施策: 4 件
  議会議事録: 3 件

収集完了: 42 件
```

> **海老名市の情報だけ集めたい場合：**
> ```bash
> node dist/index.js collect --local-only
> ```

#### 使い方 (B)：情報収集から質問生成まで一括で行う（API キー必要）

```bash
node dist/index.js run
```

**これは何をするの？**
1. まず全サイトから情報を収集します（使い方Aと同じ）
2. 次に、カテゴリ選択メニューが表示されます
3. カテゴリを選ぶと、AI が質問案を自動生成します

**カテゴリ選択メニューの画面：**
```
質問のカテゴリを選択してください：

  0. すべてのカテゴリ（フィルタなし）
  1. 子育て・教育
  2. まちづくり・都市計画
  3. 財政・行財政改革
  4. 福祉・医療
  5. 防災・安全
  6. 環境・エネルギー
  7. 産業・経済
  8. 行政運営・DX

番号を入力してください [0]:
```

**使い方：**
- 質問したい分野の番号を入力して Enter を押します
  - 例：子育てについて質問したいなら `1` を入力
- `0` を入力するか、何も入力せずに Enter を押すと、全分野からバランスよく質問が作られます

**カテゴリ選択メニューを省略したい場合：**
```bash
# 「子育て・教育」を指定して実行
node dist/index.js run --category "子育て・教育"

# 全カテゴリで生成（メニューを表示しない）
node dist/index.js run --all
```

#### 使い方 (C)：毎朝自動で実行する

```bash
npm run schedule
```

パソコンをつけたままにしておくと、**毎朝8時**に自動で情報収集と質問生成を行います。
止めたいときは `Ctrl + C`（キーボードの Ctrl キーを押しながら C キーを押す）で停止できます。

### トラブルシューティング（うまくいかない時）

| こんな症状が出たら | こうしてください |
|------------------|---------------|
| `node: command not found` と表示される | Node.js がインストールされていません。Step 1 をやり直してください |
| `npm install` でエラーが出る | インターネット接続を確認してください |
| `ANTHROPIC_API_KEY が設定されていません` と表示される | `.env` ファイルが正しく作れていません。Step 5 を確認してください |
| `エラー:` が出て収集先のサイトが読めない | そのサイトがメンテナンス中かもしれません。他のサイトの収集は続行されるので問題ありません |
| 収集記事が 0 件 | インターネット接続を確認してください。時間をおいて再実行してみてください |
| 質問生成で `401` エラーが出る | API キーが間違っています。`.env` ファイルの中身を確認してください |
| 質問生成で `429` エラーが出る | API の利用上限に達しました。Anthropic のアカウントにクレジットがあるか確認してください |
| 質問が生成されるまで時間がかかる | AI が考えている最中です。通常1〜2分かかります。そのまま待ってください |

## 環境変数（設定の変更）

`.env` ファイルで以下の設定を変更できます。通常は `ANTHROPIC_API_KEY` だけ設定すれば動きます。

| 設定名 | 必須？ | 初期値 | 説明 |
|--------|-------|--------|------|
| `ANTHROPIC_API_KEY` | **必須** | - | Anthropic の API キー（`sk-ant-...`で始まる文字列） |
| `OUTPUT_DIR` | 任意 | `./output` | 質問案ファイルの出力先フォルダ |
| `DATA_DIR` | 任意 | `./data` | 収集データの保存先フォルダ |
| `CRON_SCHEDULE` | 任意 | `0 8 * * *` | 自動実行の時刻（デフォルト：毎朝8時） |
| `MAX_ARTICLES` | 任意 | `50` | 収集する記事の最大数 |
